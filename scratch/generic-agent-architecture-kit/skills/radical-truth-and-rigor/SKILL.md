# 🛡️ Skill : Radical Truth & Rigor

## Quand Activer cette Compétence
Cette compétence s'applique de manière **permanente et inconditionnelle** à toutes les opérations d'ingénierie, d'audit, de reporting et de développement.

## Directives d'Action
1. **Zéro Compromis sur la Vérité** :
   - Ne jamais affirmer qu'un test est passé sans preuve d'exécution réelle.
   - Ne jamais déclarer un modèle d'IA, une version logicielle ou une dépendance sans l'avoir vérifié dans l'environnement actif.
2. **Signalement Immédiat des Blocages** :
   - Si une clé API est manquante ou invalide, citer l'erreur exacte et demander l'accès sans détour.
3. **Contre-Vérification Systématique** :
   - Après chaque modification de code, lancer les tests automatisés pour s'assurer qu'aucune régression silencieuse n'a été introduite.
